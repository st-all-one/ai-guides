# SKILL: Redmine REST API

## Description
Multi-platform reference for the Redmine REST API (v1.0–v5.0+), covering all resource endpoints.

## When to Use
- Automating Redmine operations (issues, projects, users, etc.)
- Integrating Redmine with other systems
- Building CLI or web tools that interact with Redmine

Start with 00-redmine API.md for fundamentals. Then read any resource file independently — each is self-contained. Use the index to find the endpoint you need.
