# SKILL: Lit

## Description
Complete guide to Lit v3 — Web Components library with SSR support, covering fundamentals to advanced patterns.

## When to Use
- Building web components with Lit
- Creating reusable UI components across frameworks
- Implementing Shadow DOM, reactivity, and SSR
- Working with Lit directives and localization
