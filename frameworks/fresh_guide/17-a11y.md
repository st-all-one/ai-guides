# 17 — Accessibility (A11y)

> Semântica, teclado, leitores de tela, foco, formulários, cores, reduced motion, testing. Como implementar acessibilidade em Fresh.

---

## 1. Fresh Built-In A11y Features

Fresh automaticamente provê acessibilidade básica:

| Feature | Comportamento |
|---------|---------------|
| `aria-current` | Injetado em `<a>` que batem com a URL atual |
| Text escaping | Todo JSX text é HTML-escapeado — safe por default |
| Server-first render | Conteúdo chega completo no HTML — screen readers leem imediatamente |
| Semantic JSX | `<nav>`, `<main>`, `<header>` são elementos HTML reais |

```tsx
// Fresh auto-adiciona aria-current nestes links:
<nav>
  <a href="/">Home</a>          {/* aria-current="page" quando em / */}
  <a href="/docs">Docs</a>      {/* aria-current="page" ou "true" */}
</nav>
```

## 2. HTML Semântico

### 2.1 Lang + charset

```tsx

  <html lang="pt-BR">
    <head>
      <meta charset="utf-8" />
      <meta name="viewport" content="width=device-width, initial-scale=1.0" />
      <title>Meu App</title>
    </head>
    <body>

  </html>
```

### 2.2 Landmarks

Todo layout deve usar landmarks semânticos:

```tsx
// routes/_layout.tsx
export default define.layout(({ Component }) => (
  <>
    <SkipLink />
    <header>
      <nav aria-label="Navegação principal">
        <a href="/">Home</a>
        <a href="/sobre">Sobre</a>
      </nav>
    </header>
    <main id="main-content">
      <Component />
    </main>
    <footer>
      <p>&copy; 2026 Meu App</p>
    </footer>
  </>
));
```

**Landmarks obrigatórios:**

| Elemento | Propósito |
|----------|-----------|
| `<header>` | Cabeçalho do site/seção |
| `<nav>` | Navegação (com `aria-label` se múltiplas) |
| `<main>` | Conteúdo principal (um por página) |
| `<footer>` | Rodapé |
| `<aside>` | Conteúdo complementar |
| `<section>` | Seção temática (com heading) |
| `<article>` | Conteúdo autocontido |

### 2.3 Heading hierarchy

## 4. Keyboard Navigation

### 4.1 Elementos focáveis nativos

Use elementos HTML nativos sempre que possível — eles já são focáveis e acessíveis por teclado sem código extra:

```tsx
// ✅ Nativo — acessível por default
<button onClick={save}>Salvar</button>
<a href="/sobre">Sobre</a>
<input type="text" />
<select>...</select>
<textarea />
<details>
  <summary>Expandir</summary>
  <p>Conteúdo</p>
</details>

// ❌ Divs clicáveis — requerem tabindex + role + key handlers
<div onClick={save} role="button" tabindex={0}
     onKeyDown={(e) => e.key === "Enter" && save()}>
  Salvar
</div>
```

### 4.2 `focus-visible` — Indicador de foco

Tailwind tem `focus-visible:` built-in. Sem Tailwind, use pseudo-class CSS:

```css
*:focus-visible {
  outline: 2px solid var(--color-brand-500);
  outline-offset: 2px;
}

/* Remove outline para mouse, mantém para teclado */
*:focus:not(:focus-visible) {
  outline: none;
}
```

```tsx
<button class="
  focus-visible:outline-2
  focus-visible:outline-offset-2
  focus-visible:outline-brand-500
  focus:outline-none
">
  Button
</button>
```

### 4.3 Keyboard handler — Escape + Enter

```tsx
// islands/Dialog.tsx
import { useEffect, useRef } from "preact/hooks";

export default function Dialog({ open, onClose, children }: DialogProps) {
  const dialogRef = useRef<HTMLDialogElement>(null);
  const previousFocus = useRef<HTMLElement | null>(null);

  useEffect(() => {
    const dialog = dialogRef.current;
    if (!dialog) return;

    if (open) {
      previousFocus.current = document.activeElement as HTMLElement;
      dialog.showModal();
      // Move foco para primeiro elemento focável
      const firstFocusable = dialog.querySelector<HTMLElement>(
        'button, [href], input, select, textarea, [tabindex]:not([tabindex="-1"])',
      );
      firstFocusable?.focus();
    } else {
      dialog.close();
      previousFocus.current?.focus();
    }
  }, [open]);

  function handleKeyDown(e: KeyboardEvent) {
    if (e.key === "Escape") {
      onClose();
    }
  }

  return (
    <dialog
      ref={dialogRef}
      onKeyDown={handleKeyDown}
      aria-labelledby="dialog-title"
      aria-modal="true"
    >
      <h2 id="dialog-title">Título do diálogo</h2>
      {children}
      <button onClick={onClose} autofocus>Fechar</button>
    </dialog>
  );
}
```

### 4.4 Focus trap em modais

```tsx
useEffect(() => {
  if (!open) return;
  const dialog = dialogRef.current!;

  function trapFocus(e: KeyboardEvent) {
    if (e.key !== "Tab") return;

    const focusable = dialog.querySelectorAll<HTMLElement>(
      'button, [href], input, select, textarea, [tabindex]:not([tabindex="-1"])',
    );
    const first = focusable[0];
    const last = focusable[focusable.length - 1];

    if (e.shiftKey && document.activeElement === first) {
      e.preventDefault();
      last.focus();
    } else if (!e.shiftKey && document.activeElement === last) {
      e.preventDefault();
      first.focus();
    }
  }

  dialog.addEventListener("keydown", trapFocus);
  return () => dialog.removeEventListener("keydown", trapFocus);
}, [open]);
```

### 5.2 Error messages — `aria-describedby` + `aria-invalid`

```tsx
// islands/ContactForm.tsx
import { useSignal } from "@preact/signals";

export default function ContactForm() {
  const errors = useSignal<Record<string, string>>({});
  const submitting = useSignal(false);

  async function handleSubmit(e: Event) {
    e.preventDefault();
    const form = e.target as HTMLFormElement;
    const data = new FormData(form);

    errors.value = {}; // limpa erros anteriores

    if (!data.get("email")) {
      errors.value = { ...errors.value, email: "Email é obrigatório." };
      return;
    }

    submitting.value = true;
    const res = await fetch("/api/contato", { method: "POST", body: data });
    if (!res.ok) {
      const serverErrors = await res.json();
      errors.value = serverErrors;
    }
    submitting.value = false;
  }

  return (
    <form onSubmit={handleSubmit} novalidate>
      <div>
        <label htmlFor="email">Email</label>
        <input
          id="email"
          name="email"
          type="email"
          aria-invalid={!!errors.value.email}
          aria-describedby={errors.value.email ? "email-error" : undefined}
          aria-errormessage={errors.value.email ? "email-error" : undefined}
        />
        {errors.value.email && (
          <p id="email-error" class="text-red-600 text-sm" role="alert">
            {errors.value.email}
          </p>
        )}
      </div>
      <button type="submit" disabled={submitting.value}>
        {submitting.value ? "Enviando..." : "Enviar"}
      </button>
    </form>
  );
}
```

### 5.3 Server-side validation — acessível

```tsx
// routes/api/contato.ts
import { define } from "@/utils.ts";

interface FormErrors {
  name?: string;
  email?: string;
}

export const handler = define.handlers({
  async POST(ctx) {
    const form = await ctx.req.formData();
    const errors: FormErrors = {};

    const name = form.get("name")?.toString();
    const email = form.get("email")?.toString();

    if (!name || name.length < 2) errors.name = "Nome deve ter ao menos 2 caracteres.";
    if (!email || !email.includes("@")) errors.email = "Email inválido.";

    if (Object.keys(errors).length > 0) {
      return Response.json(errors, { status: 422 });
    }

    return Response.json({ success: true });
  },
});
```

### 6.2 Tabs

```tsx
// islands/Tabs.tsx
import { useSignal } from "@preact/signals";

interface Tab {
  id: string;
  label: string;
  content: string;
}

export default function Tabs({ tabs }: { tabs: Tab[] }) {
  const active = useSignal(0);
  const panelId = `tabpanel-${tabs[active.value].id}`;
  const tabListLabel = "Conteúdo da seção";

  function handleKeyDown(e: KeyboardEvent, index: number) {
    let next = index;
    if (e.key === "ArrowRight") next = (index + 1) % tabs.length;
    if (e.key === "ArrowLeft") next = (index - 1 + tabs.length) % tabs.length;
    if (e.key === "Home") next = 0;
    if (e.key === "End") next = tabs.length - 1;

    if (next !== index) {
      e.preventDefault();
      active.value = next;
      document.getElementById(`tab-${tabs[next].id}`)?.focus();
    }
  }

  return (
    <div>
      <div role="tablist" aria-label={tabListLabel}>
        {tabs.map((tab, i) => (
          <button
            key={tab.id}
            id={`tab-${tab.id}`}
            role="tab"
            aria-selected={active.value === i}
            aria-controls={`tabpanel-${tab.id}`}
            tabindex={active.value === i ? 0 : -1}
            onClick={() => active.value = i}
            onKeyDown={(e) => handleKeyDown(e, i)}
          >
            {tab.label}
          </button>
        ))}
      </div>
      {tabs.map((tab, i) => (
        <div
          key={tab.id}
          id={`tabpanel-${tab.id}`}
          role="tabpanel"
          aria-labelledby={`tab-${tab.id}`}
          hidden={active.value !== i}
          tabindex={0}
        >
          {tab.content}
        </div>
      ))}
    </div>
  );
}
```

### 6.3 Toggle / Switch

```tsx
// islands/Toggle.tsx
import { useSignal } from "@preact/signals";

export default function Toggle({ label, onChange }: ToggleProps) {
  const checked = useSignal(false);

  function toggle() {
    checked.value = !checked.value;
    onChange?.(checked.value);
  }

  return (
    <button
      role="switch"
      aria-checked={checked.value}
      aria-label={label}
      onClick={toggle}
      onKeyDown={(e) => e.key === " " && (e.preventDefault(), toggle())}
      class={checked.value ? "bg-brand-500" : "bg-gray-300"}
    >
      <span aria-hidden="true">{checked.value ? "ON" : "OFF"}</span>
    </button>
  );
}
```

### 6.4 Dropdown / Menu

```tsx
// islands/Dropdown.tsx
import { useSignal, useComputed } from "@preact/signals";
import { useEffect, useRef } from "preact/hooks";

export default function Dropdown({ label, items }: DropdownProps) {
  const isOpen = useSignal(false);
  const menuRef = useRef<HTMLDivElement>(null);
  const buttonRef = useRef<HTMLButtonElement>(null);
  const activeIndex = useSignal(-1);
  const menuId = `dropdown-${label.replace(/\s+/g, "-").toLowerCase()}`;

  useEffect(() => {
    if (!isOpen.value) return;

    function handleClickOutside(e: MouseEvent) {
      if (menuRef.current && !menuRef.current.contains(e.target as Node)) {
        isOpen.value = false;
      }
    }

    function handleEscape(e: KeyboardEvent) {
      if (e.key === "Escape") {
        isOpen.value = false;
        buttonRef.current?.focus();
      }
    }

    document.addEventListener("click", handleClickOutside);
    document.addEventListener("keydown", handleEscape);
    return () => {
      document.removeEventListener("click", handleClickOutside);
      document.removeEventListener("keydown", handleEscape);
    };
  }, [isOpen.value]);

  function handleMenuKeyDown(e: KeyboardEvent) {
    if (e.key === "ArrowDown") {
      e.preventDefault();
      activeIndex.value = Math.min(activeIndex.value + 1, items.length - 1);
    }
    if (e.key === "ArrowUp") {
      e.preventDefault();
      activeIndex.value = Math.max(activeIndex.value - 1, 0);
    }
    if (e.key === "Enter" || e.key === " ") {
      e.preventDefault();
      items[activeIndex.value]?.onClick?.();
      isOpen.value = false;
    }
  }

  function toggle() {
    isOpen.value = !isOpen.value;
    activeIndex.value = -1;
  }

  return (
    <div class="relative">
      <button
        ref={buttonRef}
        aria-expanded={isOpen.value}
        aria-haspopup="true"
        aria-controls={menuId}
        onClick={toggle}
        class="flex items-center gap-1"
      >
        {label}
        <span aria-hidden="true">{isOpen.value ? "▲" : "▼"}</span>
      </button>
      {isOpen.value && (
        <div
          ref={menuRef}
          id={menuId}
          role="menu"
          aria-label={label}
          onKeyDown={handleMenuKeyDown}
          class="absolute top-full mt-1 bg-white shadow-lg rounded border"
        >
          {items.map((item, i) => (
            <button
              key={item.id}
              role="menuitem"
              tabindex={-1}
              onClick={() => { item.onClick?.(); isOpen.value = false; }}
              class={`block w-full text-left px-4 py-2 ${
                activeIndex.value === i ? "bg-gray-100" : ""
              }`}
            >
              {item.label}
            </button>
          ))}
        </div>
      )}
    </div>
  );
}
```

## 7. Dynamic Content — `aria-live`

### 7.1 Notificações / Toasts

```tsx
// islands/Toast.tsx
import { useSignal } from "@preact/signals";

let addToast: (msg: string, type: "success" | "error") => void;

export function showToast(msg: string, type: "success" | "error" = "success") {
  addToast?.(msg, type);
}

export default function ToastContainer() {
  const toasts = useSignal<Array<{ id: number; msg: string; type: string }>>([]);

  addToast = (msg, type) => {
    const id = Date.now();
    toasts.value = [...toasts.value, { id, msg, type }];
    setTimeout(() => {
      toasts.value = toasts.value.filter((t) => t.id !== id);
    }, 5000);
  };

  return (
    <div aria-live="polite" aria-atomic="false" class="fixed bottom-4 right-4 z-50">
      {toasts.value.map((toast) => (
        <div
          key={toast.id}
          role="alert"
          class={`p-4 rounded shadow-lg ${
            toast.type === "success" ? "bg-green-500" : "bg-red-500"
          } text-white`}
        >
          {toast.msg}
        </div>
      ))}
    </div>
  );
}
```

## 12. Fresh-Specific A11y Patterns

### 12.1 Island hydration — sem flash inacessível

Fresh renderiza HTML completo no servidor ANTES de hidratar islands. Isso significa que screen readers veem conteúdo completo imediatamente — não há "carregando..." enquanto JS carrega:

```tsx
// CORRETO — Server render entrega HTML completo com estados iniciais
export default function Counter() {
  const count = useSignal(0); // valor inicial no SSR → leitor de tela vê "0"
  return (
    <div>
      <span aria-live="polite">{count}</span>
      <button onClick={() => count.value++} aria-label="Incrementar contador">
        +
      </button>
    </div>
  );
}
```

### 12.2 `useEffect` para browser-only a11y APIs

```tsx
import { useEffect, useRef } from "preact/hooks";
import { IS_BROWSER } from "fresh/runtime";

export default function FocusableIsland() {
  const ref = useRef<HTMLInputElement>(null);

  useEffect(() => {
    if (!IS_BROWSER) return;
    // APIs de acessibilidade do browser:
    ref.current?.focus();
  }, []);

  return <input ref={ref} type="text" aria-label="Buscar" />;
}
```

### 12.3 Page title dinâmico — `aria-live` + `<Head>`

```tsx
// islands/DynamicTitle.tsx
import { Head } from "fresh/runtime";
import { useSignal } from "@preact/signals";

export default function DynamicTitle() {
  const unread = useSignal(0);
  const title = `Inbox (${unread.value}) — Meu App`;

  return (
    <div>
      <Head>
        <title>{title}</title>
      </Head>
      <span aria-live="polite" aria-atomic="true">
        {unread.value > 0 ? `${unread.value} mensagens não lidas` : "Nenhuma mensagem nova"}
      </span>
    </div>
  );
}
```

### 13.1 Testar com axe-core

```ts
// a11y.test.ts
import axe from "axe-core";

const app = new App()

  const html = await res.text();

  const { violations } = await axe.run(html);
  if (violations.length > 0) {
```

```txt
Tarefa                                    → Técnica
───────────────────────────────────────────────────────────────
Idioma da página                           → <html lang="pt-BR">
Título da página                           → <title> descritivo, único
Pular navegação                            → Skip link sr-only + focus:not-sr-only
Landmarks                                  → <header> <nav> <main> <footer> <aside>
Heading hierarchy                          → 1 <h1> → <h2> → <h3>; nunca pular nível
Navegação atual destacada                  → aria-current (Fresh automático)
Botão com ícone                            → <button aria-label="..."><svg aria-hidden /></button>
Input obrigatório                          → required + aria-required="true"
Erro de validação                          → aria-describedby="error-id" + role="alert"
Modal acessível                            → <dialog> + aria-modal + focus trap + Escape
Accordion                                  → aria-expanded + aria-controls + role="region"
Tabs                                       → role="tablist/tab/tabpanel" + ArrowLeft/Right
Toggle                                     → role="switch" + aria-checked
Dropdown                                   → aria-haspopup + aria-expanded + role="menu/menuitem"
Notificação dinâmica                       → role="alert" ou aria-live="polite"
Loading                                    → aria-busy="true" + role="status"
Tabela                                     → <caption> + <th scope="col/row">
Imagem informativa                         → alt="descrição contextual"
Imagem decorativa                          → alt="" + role="presentation"
SVG informativo                            → <title> + <desc> + role="img"
Ícone decorativo                           → aria-hidden="true"
Animação reduzida                          → prefers-reduced-motion / motion-reduce:
High contrast                              → prefers-contrast / forced-colors
Leitor de tela apenas                      → sr-only Tailwind utility
Foco teclado                               → focus-visible:outline-* (não focus:outline-none)
Browser-only a11y API                      → useEffect + IS_BROWSER guard
Título dinâmico (island)                   → <Head><title> + aria-live no conteúdo
Testar acessibilidade                      → axe-core + Lighthouse + teclado
```
