# Programação Orientada a Objetos (PHP 7.4)

Recursos de OOP introduzidos ou reforçados no PHP 7.4. O documento comum (7.2)
já cobre classes, interfaces, traits, métodos mágicos tradicionais, exceções e
classes anônimas. Aqui documentamos especificamente: **`__serialize`/`__unserialize`**,
a classe **`WeakReference`**, o uso de **propriedades tipadas em classes** e a
**exceção de `__toString()`** (permitida no 7.4).

> Fora de escopo (8.x): diversos recursos de tipagem e metadados de versões 8.x.
> Não os use.

## 1. Serialização customizada: `__serialize` / `__unserialize` (PHP 7.4)

Novos métodos mágicos que substituem a dupla `__sleep`/`__wakeup` e a interface
`Serializable` (esta última obsoleta em versões recentes). Eles recebem/devolvem
um **array associativo** com o estado completo do objeto — mais robusto e sem as
armadilhas de nomes de `__sleep`.

```php
<?php
class Conexao
{
    private $link;
    private $dsn;

    public function __construct(string $dsn)
    {
        $this->dsn = $dsn;
        $this->link = null; // recurso não serializável
    }

    public function __serialize(): array
    {
        return [
            'dsn' => $this->dsn,
            // 'link' é intencionalmente omitido
        ];
    }

    public function __unserialize(array $data): void
    {
        $this->dsn = $data['dsn'];
        $this->link = null; // reconectar sob demanda
    }
}
```

### Precedência

`__serialize`/`__unserialize` **têm precedência** sobre `__sleep`/`__wakeup`
quando definidos. Se você definir apenas `__sleep`, o motor usa `__sleep`;
se definir `__serialize`, usa `__serialize`. Recomenda-se adotar `__serialize`
no 7.4 para novo código.

### Exemplo prático (objeto de valor imutável)

```php
<?php
final class Ponto
{
    private int $x;
    private int $y;

    public function __construct(int $x, int $y)
    {
        $this->x = $x;
        $this->y = $y;
    }

    public function __serialize(): array
    {
        return ['x' => $this->x, 'y' => $this->y];
    }

    public function __unserialize(array $data): void
    {
        $this->x = $data['x'];
        $this->y = $data['y'];
    }

    public function x(): int { return $this->x; }
    public function y(): int { return $this->y; }
}

$copia = unserialize(serialize(new Ponto(1, 2)));
var_dump($copia->x(), $copia->y()); // int(1) int(2)
```

## 2. `WeakReference` (PHP 7.4)

Permite reter uma referência a um objeto **sem impedir** que ele seja destruído.
Útil para caches, observadores e estruturas que não devem forçar retenção de
memória. Se o objeto original for coletado, `WeakReference::get()` retorna `null`.

```php
<?php
$obj = new stdClass();
$weakref = WeakReference::create($obj);

var_dump($weakref->get() === $obj); // bool(true)

unset($obj);

var_dump($weakref->get()); // NULL (objeto foi coletado)
```

Detalhes:

- `WeakReference::create(object $object): WeakReference` — cria a referência.
- `get(): ?object` — retorna o objeto ou `null` se já foi destruído.
- Criar uma weak reference **não** incrementa o refcount do objeto.
- `WeakReference` **não pode ser serializada**.

### Caso de uso: cache que não vaza memória

```php
<?php
class CacheFraco
{
    private array $itens = [];

    public function set(string $chave, object $valor): void
    {
        $this->itens[$chave] = WeakReference::create($valor);
    }

    public function get(string $chave): ?object
    {
        if (!isset($this->itens[$chave])) {
            return null;
        }
        return $this->itens[$chave]->get(); // null se foi coletado
    }
}
```

> Um tipo de mapa com referências fracas é do PHP 8.0 e **não** faz parte deste
> documento.

## 3. Propriedades tipadas em classes (link para Tipagem 7.4)

No 7.4 as propriedades podem declarar tipo. Isso é o núcleo do estado fortemente
tipado de uma classe. Resumo (detalhes em `11-tipagem-74.md`):

```php
<?php
class Produto
{
    public int $id;
    public string $nome;
    public ?float $preco;

    public function __construct(int $id, string $nome, ?float $preco = null)
    {
        $this->id = $id;
        $this->nome = $nome;
        $this->preco = $preco;
    }
}
```

Regras-chave:

- Tipos permitidos: `int`, `float`, `string`, `bool`, `array`, `iterable`,
  `object`, classes, interfaces, `self`, `parent`, `?Tipo`. **Não** `callable`.
- Propriedades tipadas devem ser inicializadas antes da leitura (senão `Error`).
- A interação com `__get`/`__set` não "resgata" propriedades tipadas não
  inicializadas.

## 4. Exceções a partir de `__toString()` (PHP 7.4)

No 7.4 lançar exceções de dentro de `__toString()` é permitido (antes era erro
fatal). Erros recuperáveis em conversões de string viraram `Error`.

```php
<?php
class Relatorio
{
    public function __toString(): string
    {
        if ($this->pronto === false) {
            throw new RuntimeException('Relatório não está pronto');
        }
        return 'conteúdo';
    }
}
```

Use com moderação: `__toString` é frequentemente chamado em contextos de string,
então trate o chamador adequadamente.

## 5. Classes anônimas (revisão, 7.0+)

Ainda válidas no 7.4 e úteis para implementações pontuais:

```php
<?php
$logger = new class {
    public function info(string $msg): void
    {
        error_log($msg);
    }
};
```

Podem implementar interfaces, estender classes e usar `use` — vide documento
comum de POO.

## 6. Métodos mágicos disponíveis no 7.4

| Método | Disponível | Notas no 7.4 |
|---|---|---|
| `__construct`/`__destruct` | 7.2 | — |
| `__get`/`__set`/`__isset`/`__unset` | 7.2 | — |
| `__call`/`__callStatic` | 7.2 | — |
| `__toString` | 7.2 | **pode lançar exceção** (7.4) |
| `__invoke` | 7.2 | — |
| `__sleep`/`__wakeup` | 7.2 | ainda válidos |
| `__serialize`/`__unserialize` | **7.4** | novo, tem precedência |
| `__set_state` | 7.2 | — |
| `__clone`/`__debugInfo` | 7.2 | — |

> Não use a interface `Serializable` como abordagem preferencial — está
> obsoleta em versões recentes; prefira `__serialize`/`__unserialize`.

## 7. Diretrizes

- Adote `__serialize`/`__unserialize` para nova serialização customizada.
- Use `WeakReference` para referências que não devem reter objetos (caches).
- Use propriedades tipadas para contratos de estado fortes; inicialize no
  construtor.
- Evite lançar de `__toString` em excesso; prefira métodos explícitos quando a
  falha for esperada.

## 8. Resumo

- `__serialize`/`__unserialize` (7.4): serialização via array associativo.
- `WeakReference` (7.4): referência não retentiva; `create()`/`get()`.
- Propriedades tipadas em classes (7.4): estado tipado (vide `11-tipagem-74.md`).
- `__toString` pode lançar exceções (7.4).
- Sem os recursos de versões 8.x mencionados como fora de escopo acima (esses são
  de versões posteriores).
