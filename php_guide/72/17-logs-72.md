# Logs no PHP 7.2 (além do básico)

Este suplemento cobre o registro de erros e eventos disponível no 7.2. Todo o
conteúdo é válido em 7.2.

> Aviso de escopo: no 7.2 o 3º parâmetro `$errcontext` de `set_error_handler`
> está **deprecated** (removido no 8.0). Não o utilize. Nada de recursos de
> log de 7.3+/8.x.

## 1. Níveis de erro

| Constante | Significado |
|---|---|
| `E_ERROR` | erro fatal em tempo de execução |
| `E_WARNING` | aviso em tempo de execução (não fatal) |
| `E_NOTICE` | nota (possível problema) |
| `E_DEPRECATED` | uso de recurso descontinuado |
| `E_USER_ERROR` / `E_USER_WARNING` / `E_USER_NOTICE` / `E_USER_DEPRECATED` | gerados por `trigger_error()` |
| `E_RECOVERABLE_ERROR` | erro capturável (ex.: falha de type hint) |
| `E_ALL` | todos os níveis (inclui deprecations no 7.2) |

```php
<?php
error_reporting(E_ALL);          // reporta tudo
error_reporting(E_ALL & ~E_DEPRECATED); // tudo, menos deprecations
```

## 2. `error_log` — destinos

```php
<?php
// 0: para o log do PHP (error_log ini ou syslog)
error_log('Mensagem de erro');

// 1: envia por e-mail
error_log('Falha crítica', 1, 'admin@example.com');

// 2: via syslog (depreciado o uso direto; prefira openlog/syslog)
error_log('Via syslog', 2);

// 3: arquivo específico
error_log('Linha de log', 3, '/var/log/app.log');
```

## 3. Syslog

```php
<?php
openlog('minhaApp', LOG_PID | LOG_ODELAY, LOG_LOCAL0);
syslog(LOG_WARNING, 'Algo estranho aconteceu');
closelog();
```

## 4. Handlers personalizados

### `set_error_handler` (sem `$errcontext`)

No 7.2, **não** use o 3º parâmetro `$errcontext` (deprecated). Use apenas
`($errno, $errstr, $errfile, $errline)`.

```php
<?php
set_error_handler(function (int $errno, string $errstr, string $errfile = '', int $errline = 0) {
    $msg = sprintf('[%d] %s em %s:%d', $errno, $errstr, $errfile, $errline);
    error_log($msg, 3, '/var/log/app.log');
    return false; // false = deixa o handler interno do PHP também processar
});

trigger_error('Isso é um aviso', E_USER_WARNING);
```

### `set_exception_handler`

```php
<?php
set_exception_handler(function (Throwable $e) {
    error_log('Exceção não capturada: ' . $e->getMessage());
    http_response_code(500);
    echo "Erro interno.";
});

throw new RuntimeException('boom'); // capturado acima
```

### `register_shutdown_function`

Executado ao fim da requisição — ideal para log de erros fatais.

```php
<?php
register_shutdown_function(function () {
    $erro = error_get_last();
    if ($erro !== null && in_array($erro['type'], [E_ERROR, E_PARSE, E_CORE_ERROR], true)) {
        error_log('Fatal: ' . $erro['message']);
    }
});
```

## 5. `trigger_error` e utilidades

```php
<?php
trigger_error('Recurso obsoleto', E_USER_DEPRECATED);

$ultimo = error_get_last();   // último erro ocorrido
var_dump($ultimo['type'], $ultimo['message']);

error_clear_last();           // limpa o último erro (7.0+)
```

## 6. Diretivas de log (php.ini / .user.ini)

| Diretiva | Descrição |
|---|---|
| `log_errors` | ativa registro em log |
| `error_log` | destino (arquivo, syslog, e-mail conforme `error_log()`) |
| `error_reporting` | quais níveis reportar |
| `display_errors` | mostra na saída (off em produção) |
| `display_startup_errors` | erros de startup do PHP |
| `log_errors_max_len` | tamanho máximo da linha de log |

## 7. Exemplo de fluxo completo

```php
<?php
error_reporting(E_ALL);
ini_set('log_errors', '1');
ini_set('error_log', '/var/log/app.log');
ini_set('display_errors', '0');

set_error_handler(function ($errno, $errstr, $errfile, $errline) {
    error_log(sprintf('[%s] %s @ %s:%d', $errno, $errstr, $errfile, $errline), 3, '/var/log/app.log');
    return true;
});

set_exception_handler(function (Throwable $e) {
    error_log('Exceção: ' . $e, 3, '/var/log/app.log');
});

register_shutdown_function(function () {
    if (($e = error_get_last()) && $e['type'] === E_ERROR) {
        error_log('Fatal: ' . $e['message'], 3, '/var/log/app.log');
    }
});
```

## 8. Resumo

Use níveis explícitos, `set_error_handler`/`set_exception_handler` (sem
`$errcontext`), `error_log` com destino 3 para arquivo, e `register_shutdown_function`
para capturar fatais. Em produção, `display_errors=Off` e `log_errors=On`.
