# Programação Orientada a Objetos no PHP 7.2 (além do básico)

Este suplemento descreve a OOP completa disponível no 7.2, indo além da base.
Todo o código é válido em 7.2.

> Aviso de escopo: **não** existem no 7.2 diversos recursos de orientação a
> objetos de versões posteriores, como certos mecanismos de serialização e de
> definição de membros. Use as construções clássicas compatíveis com 7.2 (por
> exemplo, `__sleep`/`__wakeup` para serialização).

## 1. Classes, visibilidade e membros

```php
<?php
class Pessoa
{
    public $nome;
    protected $idade;
    private $senha;

    public function __construct(string $nome, int $idade) {
        $this->nome = $nome;
        $this->idade = $idade;
    }

    final public function apresentar(): string {
        return "{$this->nome}, {$this->idade} anos";
    }
}
```

## 2. `abstract`, `interface`, `trait`

```php
<?php
abstract class Animal
{
    abstract public function emitirSom(): string;
}

interface Nadador
{
    public function nadar(): void;
}

trait Registravel
{
    public function log(string $msg): void {
        echo $msg;
    }
}

class Peixe extends Animal implements Nadador
{
    use Registravel;

    public function emitirSom(): string {
        return "glub glub";
    }

    public function nadar(): void {
        $this->log("nadando");
    }
}
```

## 3. Constantes de classe com visibilidade

Desde o PHP 7.1 (ver `10-sintaxe-recursos-72.md`):

```php
<?php
class Status
{
    public const ATIVO    = 1;
    protected const INTERNO = 2;
    private const SEGREDO  = 3;
}
```

## 4. Métodos mágicos disponíveis em 7.2

Todos estes existem antes do 7.4 e são válidos:

| Método | Propósito |
|---|---|
| `__construct` / `__destruct` | ciclo de vida |
| `__call` / `__callStatic` | acesso a método inexistente |
| `__get` / `__set` / `__isset` / `__unset` | acesso a propriedade inexistente |
| `__sleep` / `__wakeup` | serialização (usar estes, não `__serialize`) |
| `__toString` | conversão para string |
| `__invoke` | objeto chamável |
| `__set_state` | usado por `var_export` |
| `__clone` | clonagem |
| `__debugInfo` | `var_dump` personalizado |

```php
<?php
class Caixa
{
    private $dados = [];

    public function __get($k) {
        return $this->dados[$k] ?? null;
    }

    public function __set($k, $v) {
        $this->dados[$k] = $v;
    }

    public function __isset($k) {
        return isset($this->dados[$k]);
    }

    public function __toString(): string {
        return json_encode($this->dados);
    }

    public function __invoke($x) {
        return $x * 2;
    }

    public function __debugInfo(): array {
        return ['chaves' => array_keys($this->dados)];
    }
}

$c = new Caixa();
$c->nome = 'Ana';
echo $c->nome;     // 'Ana'
echo $c;           // JSON
echo $c(21);       // 42 (invokable)
```

### `__sleep` / `__wakeup` (serialização em 7.2)

```php
<?php
class Sessao
{
    public $id;
    private $token;

    public function __sleep(): array {
        return ['id'];           // só 'id' é serializado
    }

    public function __wakeup(): void {
        $this->token = regerarToken();
    }
}
```

## 5. Late Static Binding

```php
<?php
class Base
{
    public static function criar(): static {
        return new static();
    }

    public static function quem(): string {
        return static::class;
    }
}

class Filha extends Base {}

echo Filha::quem(); // 'Filha'
```

> `static` como tipo de retorno (`static`) funciona em 7.2 dentro de métodos
> que realmente retornam a instância derivada conforme LSB.

## 6. Classes anônimas

Desde o PHP 7.0. Úteis para implementações descartáveis / mocks.

```php
<?php
$logger = new class implements Nadador {
    public function nadar(): void {
        echo "splash";
    }
};

var_dump($logger instanceof Nadador); // true
```

## 7. Exceções e erros

Desde o PHP 7.0, `Throwable` é a interface raiz; `Exception` e `Error` a
implementam. Use multi-catch (7.1).

```php
<?php
try {
    fazer();
} catch (InvalidArgumentException | RuntimeException $e) {
    echo "Lógica inválida: " . $e->getMessage();
} catch (Error $e) {
    // Erros fatais agora são capturáveis como objetos Error
    echo "Erro fatal: " . $e->getMessage();
} finally {
    echo "fim";
}
```

### Hierarquia de erros relevantes (7.0+)

- `Throwable`
  - `Exception`
    - `RuntimeException`, `InvalidArgumentException`, `LogicException`…
  - `Error`
    - `TypeError`, `ArgumentCountError`, `ParseError`, `ArithmeticError`,
      `DivisionByZeroError`, `AssertionError` (7.0)

```php
<?php
function somar(int $a, int $b): int {
    return $a + $b;
}

try {
    somar(1, "x");        // TypeError
} catch (TypeError $e) {
    echo $e->getMessage();
}

try {
    echo 1 / 0;           // DivisionByZeroError em operação
} catch (DivisionByZeroError $e) {
    echo "divisão por zero";
}
```

## 8. Sobrescrita de método abstrato (7.2)

Uma classe abstrata pode estender outra abstrata e sobrescrever o método
abstrato (mantendo covariância/contranvariância permitidas).

```php
<?php
abstract class A {
    abstract public function test(string $s);
}

abstract class B extends A {
    abstract public function test($s): int;  // sobrescrita permitida no 7.2
}
```

## 9. Resumo

A OOP do 7.2 é completa para a maioria dos sistemas: herança, interfaces,
traits, visibilidade, constantes visíveis, LSB, classes anônimas, geradores,
e tratamento de erros via `Throwable`/`Error`. Use `__sleep`/`__wakeup` para
serialização customizada.
