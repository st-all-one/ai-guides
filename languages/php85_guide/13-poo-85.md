# POO no PHP 8.5

Além do `clone()` com substituição de propriedades (capítulo 10), o 8.5
aperfeiçoa atributos, visibilidade e reflexão. O modelo de objetos permanece o
do 8.4: enums, readonly, property hooks, lazy objects e visibilidade
assimétrica continuam disponíveis e são a base recomendada para código novo.

## Fontes

- `source/UPGRADING:47-51,181-214,744-747,786-827,878-879`.
- `source/Zend/tests/clone/clone_with_001.phpt`.
- `https://www.php.net/releases/8.5/en.php`.

### Clone With em objetos imutáveis

O padrão *with-er* para `readonly class` torna-se trivial
(`source/UPGRADING:744-746`). A visibilidade é respeitada conforme o escopo
chamador (`source/Zend/tests/clone/clone_with_002.phpt:6-31`) e hooks `set`
são executados (`source/Zend/tests/clone/clone_with_005.phpt:40-64`).

```php
<?php
declare(strict_types=1);

readonly class Dinheiro
{
    public function __construct(
        public int $centavos,
        public string $moeda = 'BRL',
    ) {}

    public function somar(self $outro): self
    {
        if ($outro->moeda !== $this->moeda) {
            throw new InvalidArgumentException('moedas diferentes');
        }
        return clone($this, ['centavos' => $this->centavos + $outro->centavos]);
    }
}
```

> `__clone()` continua sendo invocado. Se ele tiver efeitos colaterais,
> confirme que a substituição não viola invariantes da classe.

### `#[\NoDiscard]` em métodos de domínio

Marque métodos cujo retorno não pode ser ignorado — por exemplo, validações
que retornam um novo objeto em vez de lançar exceção
(`source/UPGRADING:189-196`).

```php
#[\NoDiscard]
public function validar(): self
{
    return $this->centavos >= 0
        ? $this
        : throw new DomainException('valor negativo');
}
```

### Atributos em constantes e `#[\Deprecated]`

O 8.5 permite atributos em constantes de compile-time não-classe e aplica
`#[\Deprecated]` a constantes (`source/UPGRADING:200-203`). Reflexão foi
estendida: `ReflectionConstant::getAttributes()`, `getFileName()`,
`getExtension()` e `getExtensionName()` (`source/UPGRADING:786-791`).

```php
final class Config
{
    #[Deprecated('use TIMEOUT_MS', since: '8.5')]
    public const int TIMEOUT = 30;

    public const int TIMEOUT_MS = 30_000;
}

$const = new ReflectionConstant(Config::class, 'TIMEOUT');
foreach ($const->getAttributes() as $attr) {
    echo $attr->getName(), PHP_EOL; // Deprecated
}
```

### `#[\Override]` em propriedades

O atributo, antes restrito a métodos, agora cobre propriedades
(`source/UPGRADING:208-209`). Use para detectar refactoring que removeu uma
propriedade da classe pai.

```php
abstract class Base { protected string $rotulo = 'base'; }

final class Filha extends Base
{
    #[\Override]
    protected string $rotulo = 'filha';
}
```

### Visibilidade assimétrica estática

`public private(set)` / `public protected(set)` em propriedades `static`
(`source/UPGRADING:197-198`) permite expor leitura sem expor escrita:

```php
final class Metricas
{
    public protected(set) static int $requisicoes = 0;

    public static function registrar(): void
    {
        self::$requisicoes++;
    }
}
```

### Promoção `final` e `#[\DelayedTargetValidation]`

- `final` em propriedades promovidas (`source/UPGRADING:206-207`).
- `#[\DelayedTargetValidation]` adia erros de alvo inválido de atributos do
  core para o momento de `ReflectionAttribute::newInstance()`
  (`source/UPGRADING:47-51,210-214`). É mecanismo de compatibilidade, não
  padrão de projeto.

### `Closure::getCurrent()` e introspecção

`Closure::getCurrent()` devolve a closure em execução
(`source/UPGRADING:747`). `ReflectionProperty::getMangledName()` foi introduzida
(`source/UPGRADING:792`) — útil para depurar propriedades com nomes privados
em herança. `ReflectionConstant` deixou de ser `final`
(`source/UPGRADING:878-879`).

### Banimentos e armadilhas do 8.5 em POO

| Prática | Status | Fonte |
| --- | --- | --- |
| `ArrayObject`/`ArrayIterator` com objetos | depreciado | `source/UPGRADING:570-571` |
| `ArrayObject` com enums | não aceito | `source/UPGRADING:161-163` |
| `SplObjectStorage::contains/attach/detach` | depreciado; use `offset*` | `source/UPGRADING:565-569` |
| `__sleep()`/`__wakeup()` | soft-deprecated; use `__serialize()`/`__unserialize()` | `source/UPGRADING:408-410` |
| `__debugInfo()` retornando `null` | depreciado; retorne `[]` | `source/UPGRADING:379-381` |
| Clonar `DOMNamedNodeMap`, `DOMNodeList` etc. | falha | `source/UPGRADING:70-74` |
| Binding inválido de closures | depreciado | `source/UPGRADING:390-399` |

## Verificação

- Teste `clone($obj, [...])` com `__clone()` e hooks em um script throwaway.
- Rode `php -l` e `php -d error_reporting=E_ALL` para capturar depreciações.
- Confirme que nenhum `__sleep`/`__wakeup` permanece em código novo.
